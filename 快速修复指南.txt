💡 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1: npm 警告 "Unknown builtin config"
A1: 这是警告不是错误，可以忽略。或运行：
    npm config delete globalignorefile
    npm config delete python

Q2: Sharp 安装失败 "gyp ERR! build error"
A2: 需要安装编译工具（见上方 Sharp 特殊处理）

Q3: 权限错误 "EACCES: permission denied"
A3: 使用 sudo 或修改目录权限：
    sudo chown -R $USER:$USER node_modules
    npm install

Q4: 网络超时（国内服务器）
A4: 使用淘宝镜像：
    npm install --registry=https://registry.npmmirror.com

Q5: 端口被占用 "EADDRINUSE"
A5: 
    # 查看占用
    netstat -ano | findstr :7788
    # 或 Linux
    lsof -i :7788
    
    # 杀死进程
    taskkill /F /PID <进程ID>  # Windows
    kill -9 <进程ID>           # Linux
